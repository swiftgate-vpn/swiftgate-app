# SwiftGate — приложения

Готовые приложения SwiftGate VPN. Исходного кода здесь нет, только файлы для установки.

Файлы лежат прямо здесь, в папках. Откройте нужную папку, нажмите на файл и затем кнопку **Download** (значок ↓ справа).

| Устройство | Файл | Как поставить |
|---|---|---|
| Windows | [SwiftGate-Windows-Setup.exe](Windows/SwiftGate-Windows-Setup.exe) | запустить установщик |
| Mac | [SwiftGate-Mac.dmg](Mac/SwiftGate-Mac.dmg) | открыть и **обязательно перетащить SwiftGate в «Программы»** (из окна образа VPN не включится). Первый запуск: Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть» |
| Android | [SwiftGate-Android.apk](Android/SwiftGate-Android.apk) | открыть файл на телефоне |
| Android TV | [SwiftGate-AndroidTV.apk](AndroidTV/SwiftGate-AndroidTV.apk) | с флешки или через Downloader |
| iPhone | [SwiftGate-iPhone-unsigned.ipa](iPhone/SwiftGate-iPhone-unsigned.ipa) | без подписи, ставится через Sideloadly или AltStore; VPN включается через приложение Happ |

Подключить телевизор или компьютер: на нём выберите вход по коду, на телефоне в приложении — «Подписка» → «Подключить устройство». Устройство рядом найдётся по Bluetooth, либо введите код с экрана.

Войти в приложение можно через Telegram или по личной ссылке: скопируйте её в боте («Мой аккаунт») и нажмите «Войти по личной ссылке» → «Вставить ссылку и войти».
